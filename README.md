## Описание задачи

<!-- Кратко опишите задачу: что предсказываем, какой датасет, метрика качества -->

**Задача:** Классификация

**Датасет:** F1 Strategy Dataset | Pit Stop Prediction, https://www.kaggle.com/datasets/aadigupta1601/f1-strategy-dataset-pit-stop-prediction

**Целевая метрика:** F2-Score

В задаче классификации редких событий, таких как пит-стопы важнее не пропустить положительный класс, чем найти ложно положительный. 
Поэтому в этой задаче прицел в Recall. 
F1 метрика отражает сбалансированное, но не репрезентативное значение, а вот F2 метрика как раз усиливает вклад Recall в общую оценку

## Результаты

Вот таблица, составленная по различным моделям бинарной классификации:

| Модель                  | Precision | Recall | F2 Score | Примечание                                    |
|-------------------------|-----------|--------|---------|-----------------------------------------------|
| Base logreg             | 0.70 | 0.62 | 0.33    | Базовая модель не справляется                 |
| SVM                     | 0.63 | 0.50 | 0.64    |                                               |
| Random forest           | 0.97 | 0.96 | 0.94    | Лучший результат                              |
| Random forest (reduced) | 0.95 | 0.94 | 0.91    | Уменьшенная размерность (без пилота и трассы) |
| XGBoost                 | 0.95 | 0.94 | 0.91    |                                               |

Из результатов экспериментов можно заключить, что лучшей моделью оказался Random Forest на всех признаках (без уменьшения размерности),
однако та же модель, но с уменьшенной размерностью показала довольно неплохой результат (F2 ниже на 2%)

Мною было принято решение оставить для дальнейшей работы модель Random Forest без уменьшения размерности, так как информация о пилоте и трассе достаточно значима,
и не стоит терять на этом точность предсказаний.
